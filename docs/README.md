# 🥖 Panadería - Predicción de Demanda

## Stack
- Frontend: React + Vite + JavaScript (.jsx)
- Backend: Node.js + Express + MySQL (.js)
- ML: Python + Scikit-Learn (Random Forest)

## Instalación
1. `cd frontend && npm install && npm run dev`
2. `cd backend && npm install && npm run dev`
3. `cd ml-service && pip install -r requirements.txt`
4. Entrenar: `python src/models/random_forest.py`
5. API ML: `python src/api/main.py`
